# Windows platform folder — Phase 0 placeholder

This folder is a Phase 0 stub. The full Windows platform files
(CMake, runner, resources) are generated by `flutter create` on a
machine with Flutter installed — see android/README.md for the exact
command (`--platforms android,windows`).

A Windows .exe CANNOT be compiled on this Linux VM. The Windows build
must be run from a Windows PC (see docs/PHASE0.md).
